# Repository Instructions

## AI Assistance Attribution

Every commit created in this repository must include both of the following
`Assisted-by` trailers, one per line, in the commit footer:

```text
Assisted-by: OpenAI Codex
Assisted-by: DeepSeek
```

Separate the footer from the commit body with a blank line. Do not combine the
trailers or omit either line unless the user explicitly requests different
attribution.

Do not use `Co-authored-by` for AI or tool assistance unless the user supplies
verified identities and email addresses. Never invent an email address.
