# Repository Instructions

## Commit Attribution

Every commit created in this repository must include both of the following
`Co-authored-by` trailers, one per line, in the commit footer:

```text
Co-authored-by: OpenAI Codex <codex@openai.com>
Co-authored-by: DeepSeek <noreply@deepseek.com>
```

Separate the footer from the commit body with a blank line. Do not combine the
trailers or omit either line unless the user explicitly requests different
attribution.
